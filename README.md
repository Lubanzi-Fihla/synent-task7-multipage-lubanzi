# Task 7: Multi-Page Corporate Website

##  Project Purpose
The purpose of this assignment was to construct a professional multi-page website architecture. It focuses on maintaining structural layout consistency, uniform navigation components, and global styling systems across distinct files.

##  Technologies Used
* **HTML5:** Structured across 4 independent pages (`index.html`, `about.html`, `services.html`, `contact.html`).
* **CSS3:** A single shared stylesheet handling global responsiveness, alignment, and navigation highlights.

##  Key Features
* Professional **IT & Network Consultancy** company theme layout.
* Shared header navigation menu and footer components across all views.
* `.active` class state tracking to visually highlight the current active tab link.
* Integrated communication anchor tags for direct email and LinkedIn routing.
